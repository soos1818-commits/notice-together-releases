## 처음 쓰는 순서

1. 사용 모드를 ‘실제 서비스 · 최종 확인 후 게시’로 바꿉니다.
2. 내 카페 홈 주소 두 개, SOOP ID, 게시판 이름을 입력하고 ‘게시 대상 저장’을 누릅니다. 기본 주소는 반드시 본인 대상으로 바꾸세요.
3. 앱이 여는 공식 네이버·SOOP 창에서 직접 로그인합니다.
4. 제목과 내용을 쓰고 ‘세 곳에 입력하기’를 누릅니다. 이 단계에서는 게시되지 않습니다.
5. ‘게시 전 최종 확인’에서 대상과 내용을 확인하고 확인란을 체크합니다.
6. ‘확인한 글을 3곳에 게시’를 누르면 실제 등록됩니다. 게시 이력과 실제 글을 확인하세요.

## 초기 검증판 안내

v0.4.0은 실제 서비스에서 제목·본문 입력까지만 검증했습니다. 실제 등록은 로컬 가상 서비스에서 검증했고, 실제 사이트 게시 성공은 아직 검증하지 않았습니다. 일부 대상만 등록될 수 있으며, 불명확한 결과는 자동 재게시하지 않습니다. 이미지·첨부파일·서식은 지원하지 않습니다.

## 개인정보

배포물에는 개인 로그인 세션·초안·게시 이력이 포함되지 않습니다. 검토한 앱 코드에서 비밀번호나 쿠키를 수집해 별도 서버로 보내는 기능은 찾지 못했습니다. 로그인은 공식 서비스에 전송되어 처리됩니다. 로그인 유지 정보는 PC에 남고 초안·이력은 로컬 평문으로 저장됩니다. 공용 PC에서는 서비스별 ‘정보 삭제’를 이용하세요. 이 버튼은 초안·이력을 지우지 않습니다. 보안 위험이 전혀 없음을 보장하는 인증은 아닙니다.

이 앱은 네이버·SOOP 공식 프로그램이 아닙니다. EXE는 개발자 코드 서명이 없어 보안 경고나 차단이 발생할 수 있습니다. 보안 프로그램을 끄지 말고 배포자에게 문의하세요.
